web/   Modified Versions (subsets) for the HTML report, README images and mockups, made by subset.py:
       - glyphs limited to Basic Latin, Latin-1, common punctuation, arrows and math signs
         (+ box drawing, block elements and geometric shapes in the mono);
       - hinting removed; all OpenType layout features kept for the remaining glyphs;
       - renamed "Wasitme Serif" / "Wasitme Mono" (name IDs 1, 3, 4, 6, 16, 17, 21, 22), because a
         Modified Version may not use the Reserved Font Name "Plex"; version string gains "; wasitme subset".
       Copyright, licence, designer and trademark name records are kept as upstream wrote them.
