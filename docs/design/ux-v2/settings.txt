│   It runs inside Claude Code with your permissions, and can only:                                            │
│   · Re-read wasitme's status once a minute.                                                                  │
│   · Read the time, to tell when the status is out of date.                                                   │

│   · Read one file: wasitme's status file.                                                                    │
│   · See that file's size and when it changed.                                                                │
│   · Remember what it last showed.                                                                            │
│   · Open, draw and close its own pane.                                                                       │
